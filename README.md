# Travel Itinerary Planner

A full-stack web app for planning trips and organizing activities into a day-by-day itinerary.

## Planned Features

### MVP

- User signup and login
- Create, view, edit, and delete trips
- Add, edit, and delete activities
- View activities grouped by day
- Mobile-friendly interface

### Possible Future Features

- Trip budget and expense tracking
- Map showing activity locations
- Packing checklist
- Shareable, read-only itineraries
- Weather forecasts

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, Vite, TypeScript, Tailwind CSS |
| Backend | FastAPI, Python |
| Database | PostgreSQL, hosted on Supabase |
| Database access | SQLAlchemy, Alembic |
| Authentication | Supabase Auth |
| Maps (planned) | Leaflet, OpenStreetMap |
